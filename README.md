# Fungi TrackR

Fungi.TrackR is a R-Shiny based application to do fast data visualization, especially tailored for biomedical data formats.

USE:
1. Install Rstudio
2. Install dependent packages (RShiny, tidyverse, DT, etc.)
3. run "runApp()" in the directory

This app is live hosted at: https://fungitracker.shinyapps.io/FungiTrackR/
